# MERN Stack Learning Repository

This repository is created for learning, practicing, and building projects with the technologies used in the MERN stack and modern web development.

It contains assignments and practice work covering frontend fundamentals, JavaScript, React, Node.js, MongoDB, and full-stack application development.

## Purpose

The main goals of this repository are to:

- Learn the fundamentals of web development.
- Practice HTML, CSS, and JavaScript.
- Build user interfaces with React.
- Create backend applications using Node.js.
- Work with MongoDB databases.
- Understand how frontend and backend applications communicate.
- Build and improve practical MERN stack projects.
- Track learning progress through assignments and exercises.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rakshithnagaraju30/MERN_Stack.git
cd MERN_Stack
```

### 2. Open an assignment

Each assignment is maintained in its own directory. Open the directory you want to study and follow the instructions provided in its source files or its individual README, if available.

### 3. Install dependencies when required

For assignments that contain a `package.json` file, run:

```bash
npm install
```

Use the scripts listed in that assignment's `package.json` to start or test the project.

## Featured Practice Project

The `Assignment_on_MongoDB` directory contains a MERN-style to-do application for managing tasks. It demonstrates:

- A React frontend.
- A Node.js and Express backend.
- MongoDB database connectivity.
- Creating, reading, updating, and deleting tasks.
- Communication between a frontend application and backend API.

Refer to the README inside `Assignment_on_MongoDB` for project-specific setup instructions.
